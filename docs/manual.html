1. What is chem-markdown

chem-markdown is a JavaScript library for writing chemical formulas, equations and units as plain strings and showing them on web pages. Its syntax is the same as \ce{...} and \pu{...} of mhchem, the chemistry extension for MathJax and KaTeX, so formulas written for mhchem work unchanged.

  • No MathJax needed: a single <script> tag. One file, no external resources.
  • Three outputs: HTML (for pages), Unicode text (strings such as H₂O) and LaTeX (identical to mhchem).
  • mermaid-style auto rendering: write formulas in <pre class="chem"> or a Markdown ```chem block and they are rendered when the page loads.
  • Structural formulas: with SmilesDrawer loaded, structures can be drawn from SMILES.

Formulas are parsed by the bundled mhchemParser, the official parser written by the author of mhchem. Formulas are therefore interpreted exactly as mhchem interprets them, including subtle rules such as the meaning of spaces.

2. Installation

From the CDN (jsDelivr)

<script src="https://cdn.jsdelivr.net/gh/EMUYN-LLC/chem-markdown@v1.0.0/dist/chem-markdown.js"></script>
@v1.0.0 in the URL is a release tag. Always specify a tag so that the version you use stays fixed.

Self-hosting

Copy dist/chem-markdown.js from the repository to your site and load it.

<script src="chem-markdown.js"></script>

Loading it defines the global variable ChemMarkdown. In Node.js, require('./chem-markdown.js') returns the same object (the conversion functions to HTML, text and LaTeX are available).

3. Quick start

The simplest way is to write formulas in <pre class="chem">. No JavaScript is required.

<script src="chem-markdown.js"></script>

<pre class="chem">
2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3
</pre>

<p>The heat of formation of water <span class="chem">H2O</span> is <span class="pu">-286 kJ/mol</span>.</p>

Result:

2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3

The heat of formation of water H2O is -286 kJ/mol.

You can also convert strings from JavaScript.

ChemMarkdown.toHtml('H2SO4');   // HTML string
ChemMarkdown.toText('H2SO4');   // "H₂SO₄"
ChemMarkdown.toLatex('H2SO4');  // LaTeX identical to mhchem

4. Basic rules

mhchem notation is designed to "look like chemistry as written", but a few rules are worth remembering.

  • Spaces matter: A + B (spaces around) is addition, H+ (no space) is a charge. A - B is subtraction, A-B is a single bond.
  • A trailing + / - is a charge: Cl- is Cl⁻. To show a hyphen, write {-}.
  • Position decides the meaning of numbers: a number before a formula is a stoichiometric number; a number after an element or bracket is a subscript.
  • { } shows its content as-is: in {Gluconic Acid} the content is not interpreted as a formula.
  • $ $ contains math: italic variables, fractions and so on.

Spaces: addition

9. JavaScript API

All functions live on the ChemMarkdown object. options.type is 'ce' (formulas and equations, default) or 'pu' (units).

toHtml(input, options?)

Returns an HTML string. options.prefix changes the CSS class prefix (default 'chem'). In a browser, the default stylesheet is inserted into the page once.

ChemMarkdown.toHtml('H2O');
// '<span class="chem-formula"><span class="chem-term">H<sub class="chem-sub">2</sub>O</span></span>'

ChemMarkdown.toHtml('123 kJ/mol', { type: 'pu' });
ChemMarkdown.toHtml('H2O', { prefix: 'my' });  // class="my-formula" ...

document.getElementById('out').innerHTML = ChemMarkdown.toHtml('2H2 + O2 -> 2H2O');

toText(input, options?)

Returns text using Unicode superscript and subscript characters. Useful where HTML cannot be used, such as title attributes, buttons and notifications.

ChemMarkdown.toText('SO4^2-');                          // "SO₄²⁻"
ChemMarkdown.toText('N2 + 3H2 <=> 2NH3');                // "N₂ + 3 H₂ ⇌ 2 NH₃"
ChemMarkdown.toText('8.314 J K-1 mol-1', { type: 'pu' });  // "8.314 J K⁻¹ mol⁻¹"

toLatex(input, options?)

Returns exactly the LaTeX that mhchem generates. It can be displayed as-is with MathJax or KaTeX (with the mhchem extension loaded).

ChemMarkdown.toLatex('H2O');
// '{\mathrm{H}{\vphantom{A}}_{\smash[t]{2}}\mathrm{O}}'

parse(input, options?)

Returns mhchem's parse result (AST) as-is, for custom rendering.

ChemMarkdown.parse('H2O');
// [ { type_: 'chemfive', a: [], b: [], p: [], o: [{ type_: 'rm', p1: 'H' }], q: ['2'], d: [] },
//   { type_: 'chemfive', a: [], b: [], p: [], o: [{ type_: 'rm', p1: 'O' }], q: [], d: [] } ]

initialize(config) · run(options?)

Configure and run auto rendering. See 10. Auto rendering > Configuration and manual rendering.

version

The library version string (e.g. '1.0.0').

Errors

When mhchem cannot parse the input, toHtml, toText, toLatex and parse throw an Error.

try {
  ChemMarkdown.toHtml('A \\bond{?} B');
} catch (e) {
  console.log(e.message);  // "mhchem Error. Unknown bond type (?)"
}

10. Auto rendering

On a page that loads chem-markdown, markup written in a specific way is rendered automatically when the page loads (the same idea as mermaid).

In HTML

MarkupKindContent
<pre class="chem">...</pre>BlockOne formula per line; empty lines are ignored
<span class="chem">...</span>InlineA formula in running text
<pre class="pu"> · <span class="pu">Block / inlineUnits
 
<pre class="chem">
CH4 + 2O2 -> CO2 + 2H2O
Ag+ + Cl- -> AgCl v
</pre>
<p>Silver chloride <span class="chem">AgCl</span> is a white precipitate.</p>
CH4 + 2O2 -> CO2 + 2H2O
Ag+ + Cl- -> AgCl v

Silver chloride AgCl is a white precipitate.

In HTML it is safest to write < as &lt; and > as &gt; (e.g. &lt;=&gt;). The > in -> works as-is, but arrows starting with < can be mistaken for tags.

In Markdown

On pages that convert Markdown to HTML (with marked etc.), the following are rendered.

MarkupKind
```chem code blockBlock (formulas)
```pu code blockBlock (units)
Inline code `chem:H2O`Inline (formula)
Inline code `pu:123 kJ`Inline (units)
 
The heat of formation of water `chem:H2O` is `pu:-286 kJ/mol`.

```chem
2H2 + O2 -> 2H2O
```

If the Markdown is converted later, turn off automatic rendering and call run() after converting.

ChemMarkdown.initialize({ startOnLoad: false });

output.innerHTML = marked.parse(markdownText);
ChemMarkdown.run();

A working example is in examples/markdown.html.

Structural formulas (SMILES)

In formula blocks and inline elements, lines starting with smiles: are drawn as structural formulas with SmilesDrawer. Load it before chem-markdown. 

<script src="https://unpkg.com/smiles-drawer@2.0.1/dist/smiles-drawer.min.js"></script>
<script src="chem-markdown.js"></script>

<pre class="chem">
smiles: CC(=O)Oc1ccccc1C(=O)O
</pre>
<p>Benzene <span class="chem">smiles:c1ccccc1</span></p>
smiles: CC(=O)Oc1ccccc1C(=O)O

Benzene smiles:c1ccccc1

If SmilesDrawer is not loaded or the SMILES is invalid, the original text is shown in red with a console warning.

Configuration and manual rendering

ChemMarkdown.initialize({
  startOnLoad: true,   // render automatically on page load (default: true)
  prefix: 'chem',      // prefix of the generated CSS class names (default: 'chem')
  injectStyles: true,  // insert the default stylesheet into the page (default: true)
  smiles: {            // options passed to SmilesDrawer.Drawer
    width: 200,        // canvas width (default: 200)
    height: 150,       // canvas height (default: 150)
  },
});

ChemMarkdown.run();                                // render the whole page
ChemMarkdown.run({ querySelector: '.my-chem' });   // render elements matching a selector
ChemMarkdown.run({ nodes: [element1, element2] }); // render the given elements
  • Call initialize() right after loading chem-markdown (before the page finishes loading).
  • Rendered elements get data-processed="true"; calling run() repeatedly never renders anything twice, so only newly added elements are rendered.
  • Elements passed via querySelector / nodes are rendered as blocks if they are <pre> or <div>, inline otherwise. With the class pu (or language-pu) they are rendered as units.
  • Input that cannot be rendered is shown as-is with .chem-error. Hovering it shows the error message.

11. Styling (CSS)

The CSS needed for stacked scripts and arrows is inserted into the page automatically in browsers (<style id="chem-markdown-style-chem">). Text color is inherited from the surrounding text, so dark mode works as-is. Adjust fonts and sizes with CSS on the following classes. 

/* Show formulas in a serif font */
.chem-formula, .chem-pu { font-family: "Times New Roman", serif; }

/* Center auto-rendered blocks */
.chem-block { text-align: center; }

LaTeX output

toLatex returns the TeX generated by mhchem itself. It contains commands defined by mhchem such as \tripledash, so displaying it requires MathJax or KaTeX with the mhchem extension.

13. Limitations

  • TeX inside $...$: the HTML and text output can render:
    • Greek letters and common symbols (\Delta, \infty, \pm, \times, \cdot, \approx, \le, \ge, arrows ...)
    • \frac, \sqrt, ^, _
    • \text, \mathrm, \mathit, \mathbf, \underset, \overset, \underbrace, \left, \right, \color
    • Nested \ce and \pu
    Other commands (matrices, complex math ...) are shown by name with a console warning. To render them exactly, display the output of toLatex with MathJax or KaTeX.
  • Fine details: the HTML output is laid out with CSS, so positions and spacing do not match MathJax exactly. Compare them side by side with examples/mhchem.html.
  • Text output: superscripts and subscripts missing from Unicode cannot be expressed, so the result is approximate (see 12).

14. FAQ

A - becomes a charge

A trailing - is a charge. Write {-} for a hyphen or \bond{-} for a bond.

An addition turns into a charge

Put spaces around +: A + B, not A+B.

The precipitate / gas arrow does not appear

v and ^ need a space before them: BaSO4 v, H2 ^.

Nothing is rendered automatically

  • Check that the class name is chem (pu for units).
  • Elements added later by JavaScript are rendered by calling ChemMarkdown.run().
  • With initialize({ startOnLoad: false }), nothing is rendered automatically.
  • Only Markdown inline code starting with chem: / pu: is rendered.

Can it be used together with MathJax?

Yes. chem-markdown does not touch text written as $...$ or \ce{...} in the page, so it does not conflict with MathJax.

How do I migrate formulas written for MathJax?

Pass the contents of \ce{...} as-is to <span class="chem"> or toHtml(); they are interpreted the same way.

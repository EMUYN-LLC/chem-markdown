chem-markdown マニュアル

English | 日本語

バージョン ・ このページの表示例は、すべて chem-markdown 自身がその場で描いています。

1. chem-markdown とは

chem-markdown は、化学式・反応式・単位を簡単な文字列で書き、Web ページに表示するための JavaScript ライブラリです。 記法は MathJax・KaTeX の化学拡張 mhchem の \ce{...}・\pu{...} と同じなので、mhchem で書いた式をそのまま使えます。

  • MathJax 不要: <script> タグ 1 つで動きます。ファイルは 1 つで、外部ファイルの読み込みもありません。
  • 3 種類の出力: HTML (ページに表示)、Unicode テキスト (H₂O のような文字列)、LaTeX (mhchem と同じ)。
  • mermaid 風の自動変換: <pre class="chem"> や Markdown の ```chem に書くだけで、ページ読み込み時に変換されます。
  • 構造式: SmilesDrawer を読み込めば、SMILES で構造式も描けます。

式の解析には、mhchem 作者による公式パーサ mhchemParser を同梱しています。 そのため、空白の扱いなどの細かい規則も含めて、式の解釈は mhchem と同じになります。

2. 導入

CDN (jsDelivr) から読み込む

<script src="https://cdn.jsdelivr.net/gh/EMUYN-LLC/chem-markdown@v1.0.0/dist/chem-markdown.js"></script>
URL の @v1.0.0 はリリースのタグです。使うバージョンを固定するため、タグを指定してください。

ファイルを直接置く

リポジトリの dist/chem-markdown.js を自分のサイトにコピーして読み込みます。

<script src="chem-markdown.js"></script>

読み込むと、グローバル変数 ChemMarkdown が使えるようになります。Node.js では require('./chem-markdown.js') で同じオブジェクトが得られます (HTML・テキスト・LaTeX への変換関数が使えます)。

3. クイックスタート

いちばん簡単なのは、HTML に <pre class="chem"> で式を書く方法です。JavaScript を書く必要はありません。

<script src="chem-markdown.js"></script>

<pre class="chem">
2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3
</pre>

<p>水 <span class="chem">H2O</span> の生成熱は <span class="pu">-286 kJ/mol</span> です。</p>

表示結果:

2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3

水 H2O の生成熱は -286 kJ/mol です。

JavaScript から文字列として変換することもできます。

ChemMarkdown.toHtml('H2SO4');   // HTML 文字列
ChemMarkdown.toText('H2SO4');   // "H₂SO₄"
ChemMarkdown.toLatex('H2SO4');  // mhchem と同じ LaTeX

4. 記法の基本ルール

mhchem の記法は「書いたとおりに化学っぽく表示する」ように作られていますが、いくつか覚えておくべき規則があります。

  • 空白に意味がある: A + B (前後に空白) は足し算、H+ (空白なし) は電荷です。A - B は引き算、A-B は単結合です。
  • 末尾の +・- は電荷: Cl- は Cl⁻ です。ハイフンとして表示したいときは {-} と書きます。
  • 数字の位置で意味が変わる: 化学式の前の数字は係数、元素や括弧の後の数字は下付きになります。
  • { } は囲んだ部分をそのまま表示する: {Gluconic Acid} のように書くと、中身を化学式として解釈しません。
  • $ $ の中は数式: 斜体の変数や分数などを書けます。
入力表示テキスト出力説明
空白なし: 電荷
空白あり: 足し算
空白なし: 単結合
空白あり: 引き算
末尾の - は電荷
{ } の中はそのまま

9. JavaScript API

すべての関数は ChemMarkdown オブジェクトにあります。options.type は 'ce' (化学式・反応式、デフォルト) または 'pu' (単位) です。

toHtml(input, options?)

HTML 文字列を返します。options.prefix で CSS クラス名のプレフィックス (デフォルト 'chem') を変えられます。ブラウザで呼ぶと、標準 CSS がページに 1 回だけ入ります。

ChemMarkdown.toHtml('H2O');
// '<span class="chem-formula"><span class="chem-term">H<sub class="chem-sub">2</sub>O</span></span>'

ChemMarkdown.toHtml('123 kJ/mol', { type: 'pu' });
ChemMarkdown.toHtml('H2O', { prefix: 'my' });  // class="my-formula" ...

document.getElementById('out').innerHTML = ChemMarkdown.toHtml('2H2 + O2 -> 2H2O');

toText(input, options?)

Unicode の上付き・下付き文字を使ったテキストを返します。title 属性、ボタン、通知など、HTML を使えない場所に向いています。

ChemMarkdown.toText('SO4^2-');                          // "SO₄²⁻"
ChemMarkdown.toText('N2 + 3H2 <=> 2NH3');                // "N₂ + 3 H₂ ⇌ 2 NH₃"
ChemMarkdown.toText('8.314 J K-1 mol-1', { type: 'pu' });  // "8.314 J K⁻¹ mol⁻¹"

toLatex(input, options?)

mhchem が生成するのと同じ LaTeX を返します。MathJax・KaTeX (mhchem 拡張を読み込んだもの) でそのまま表示できます。

ChemMarkdown.toLatex('H2O');
// '{\mathrm{H}{\vphantom{A}}_{\smash[t]{2}}\mathrm{O}}'

parse(input, options?)

mhchem の解析結果 (AST) をそのまま返します。独自の描画をしたいときに使います。

ChemMarkdown.parse('H2O');
// [ { type_: 'chemfive', a: [], b: [], p: [], o: [{ type_: 'rm', p1: 'H' }], q: ['2'], d: [] },
//   { type_: 'chemfive', a: [], b: [], p: [], o: [{ type_: 'rm', p1: 'O' }], q: [], d: [] } ]

initialize(config) ・ run(options?)

自動変換の設定と実行です。10. 自動変換 > 設定と手動実行 を参照してください。

version

ライブラリのバージョン文字列です (例: '1.0.0')。

エラー

mhchem が解析できない式を渡すと、toHtml・toText・toLatex・parse は Error を投げます。

try {
  ChemMarkdown.toHtml('A \\bond{?} B');
} catch (e) {
  console.log(e.message);  // "mhchem Error. Unknown bond type (?)"
}

10. 自動変換

chem-markdown を読み込んだページでは、決まった書き方をした部分がページ読み込み時に自動で変換されます (mermaid と同じ仕組みです)。

HTML に書く

書き方種類内容
<pre class="chem">...</pre>ブロック1 行に 1 つの式。空行は無視
<span class="chem">...</span>インライン文中の式
<pre class="pu"> ・ <span class="pu">ブロック・インライン単位
 
<pre class="chem">
CH4 + 2O2 -> CO2 + 2H2O
Ag+ + Cl- -> AgCl v
</pre>
<p>塩化銀 <span class="chem">AgCl</span> は白色の沈殿です。</p>
CH4 + 2O2 -> CO2 + 2H2O
Ag+ + Cl- -> AgCl v

塩化銀 AgCl は白色の沈殿です。

HTML の中では < を &lt;、> を &gt; と書くのが安全です (例: &lt;=&gt;)。-> の > はそのままでも動きますが、< で始まる矢印はタグと誤解されることがあります。

Markdown に書く

Markdown を HTML に変換するページ (marked などを使うもの) では、次の書き方が変換されます。

書き方種類
```chem のコードブロックブロック (化学式)
```pu のコードブロックブロック (単位)
`chem:H2O` のインラインコードインライン (化学式)
`pu:123 kJ` のインラインコードインライン (単位)
 
水 `chem:H2O` の生成熱は `pu:-286 kJ/mol` です。

```chem
2H2 + O2 -> 2H2O
```

Markdown を後から HTML にする場合は、自動実行を止め、変換した後で run() を呼びます。

ChemMarkdown.initialize({ startOnLoad: false });

output.innerHTML = marked.parse(markdownText);
ChemMarkdown.run();

動く例は examples/markdown.html にあります。

構造式 (SMILES)

化学式のブロックやインラインで、smiles: で始まる行は構造式として描きます。描画には SmilesDrawer を使うので、chem-markdown より前に読み込んでください。 

<script src="https://unpkg.com/smiles-drawer@2.0.1/dist/smiles-drawer.min.js"></script>
<script src="chem-markdown.js"></script>

<pre class="chem">
smiles: CC(=O)Oc1ccccc1C(=O)O
</pre>
<p>ベンゼン <span class="chem">smiles:c1ccccc1</span></p>
smiles: CC(=O)Oc1ccccc1C(=O)O

ベンゼン smiles:c1ccccc1

SmilesDrawer が読み込まれていない場合や、SMILES が正しくない場合は、元の文字列を赤字で表示し、コンソールに警告を出します。

設定と手動実行

ChemMarkdown.initialize({
  startOnLoad: true,   // ページ読み込み時に自動変換する (デフォルト: true)
  prefix: 'chem',      // 出力する CSS クラス名のプレフィックス (デフォルト: 'chem')
  injectStyles: true,  // 標準 CSS をページに入れる (デフォルト: true)
  smiles: {            // SmilesDrawer.Drawer に渡すオプション
    width: 200,        // canvas の幅 (デフォルト: 200)
    height: 150,       // canvas の高さ (デフォルト: 150)
  },
});

ChemMarkdown.run();                                // ページ全体を変換
ChemMarkdown.run({ querySelector: '.my-chem' });   // セレクタで指定した要素を変換
ChemMarkdown.run({ nodes: [element1, element2] }); // 要素を直接指定して変換
  • initialize() は、chem-markdown を読み込んだ直後 (ページの読み込みが終わる前) に呼んでください。
  • 一度変換した要素には data-processed="true" が付き、run() を何度呼んでも二重には変換されません。後から追加した要素だけが変換されます。
  • querySelector・nodes で指定した要素は、<pre>・<div> ならブロック、それ以外はインラインとして変換します。クラス pu (または language-pu) が付いていれば単位として変換します。
  • 変換できない式は、元の文字列を .chem-error 付きで表示します。マウスを乗せるとエラーの内容が出ます。

11. 見た目の調整 (CSS)

/* 化学式を明朝系のフォントで表示する */

/* 自動変換のブロックを中央寄せにする */
.chem-block { text-align: center; }

.chem-coef係数

.chem-arrow反応矢印 (.chem-arrow-above・.chem-arrow-below が条件)

.chem-bond結合
.chem-state状態記号
.chem-i / .chem-b斜体 / 太字
.chem-over\underset・\overset

標準 CSS を使わずにすべて自分で書く場合は initialize({ injectStyles: false }) を指定します。プレフィックスを変えた場合 (prefix: 'my')、クラス名は .my-formula のようになり、標準 CSS もそのプレフィックス用に作られます。

12. テキスト・LaTeX 出力

テキスト出力の規則

テキスト出力は Unicode の文字で表せる範囲での近似です。

要素出力例
下付き・上付きUnicode の下付き・上付き文字H₂O、SO₄²⁻
対応する文字がない添字_(...)・^(...)Li_(Li,x)
同位体上付き・下付きを前に置く¹⁴₆C
酸化数上付きのローマ数字 (I と V のみ)Feᴵᴵ
分数½ などの文字、なければ 1/3 の形½ O₂
矢印の条件→[上][下]→[MnO₂][Δ]
平衡矢印偏りのある矢印も ⇌A ⇌ B
特殊な結合近い記号┄、≂、≅
色・\underset色は無視、注記は括弧で後ろに付けるHgI₂ (red)

LaTeX 出力

toLatex は mhchem 自身が生成する TeX をそのまま返します。この TeX には \tripledash など mhchem が定義するコマンドが含まれるため、表示には mhchem 拡張を読み込んだ MathJax または KaTeX が必要です。

13. 制約

  • $...$ の中の TeX: HTML・テキスト出力で描けるのは次の範囲です。
    • ギリシャ文字、よく使う記号 (\Delta・\infty・\pm・\times・\cdot・\approx・\le・\ge・矢印など)
    • \frac・\sqrt、^・_
    • \text・\mathrm・\mathit・\mathbf、\underset・\overset・\underbrace、\left・\right、\color
    • \ce・\pu の入れ子
    これ以外のコマンド (行列や複雑な数式など) は、コマンド名をそのまま表示してコンソールに警告を出します。正確に表示するには toLatex の出力を MathJax・KaTeX で表示してください。
  • 見た目の細部: HTML 出力は CSS で組んでいるため、文字の位置や間隔は MathJax と完全には一致しません。並べて比べるには examples/mhchem.html を使ってください。
  • テキスト出力: Unicode にない上付き・下付き文字は表せないため、近似になります (12 を参照)。

14. よくある質問

電荷にしたくない - が電荷になる

末尾の - は電荷として扱われます。ハイフンにしたいときは {-}、結合にしたいときは \bond{-} と書いてください。

足し算のつもりが電荷になる

+ の前後に空白を入れてください。A+B ではなく A + B です。

沈殿・気体の矢印が出ない

v・^ の前に空白が必要です。BaSO4 v、H2 ^ と書いてください。

自動変換されない

  • クラス名が chem (単位は pu) になっているか確認してください。
  • JavaScript で後から追加した要素は、ChemMarkdown.run() を呼ぶと変換されます。
  • initialize({ startOnLoad: false }) を指定していると自動では変換されません。
  • Markdown のインラインコードは、chem:・pu: で始まるものだけが対象です。

MathJax と一緒に使える？

使えます。chem-markdown は $...$ や \ce{...} と書かれた本文には手を出さないので、MathJax の表示とぶつかりません。

MathJax で書いた式を移したい

\ce{...} の中身をそのまま <span class="chem"> や toHtml() に渡せば、同じ解釈で表示されます。

How it works

SmilesDrawer draws SMILES (e.g. water O, ethanol CCO, benzene c1ccccc1) on <canvas> elements placed in the text. For automatic embedding, see the auto rendering tab (<span class="chem">smiles:...</span>).

✨ 7. Auto rendering (mermaid-style) chem-markdown

On a page that loads chem-markdown, the following markup is rendered automatically when the page loads. Lines starting with smiles: are drawn as structural formulas with SmilesDrawer.

Blocks

<pre class="chem">
2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3
smiles: CC(=O)O
</pre>
2H2 + O2 -> 2H2O
N2 + 3H2 <=> 2NH3
smiles: CC(=O)O

Inline

Sulfuric acid <span class="chem">H2SO4</span> and
benzene <span class="chem">smiles:c1ccccc1</span>

Sulfuric acid H2SO4 is a strong acid. Benzene smiles:c1ccccc1 is an aromatic compound.

Markdown

In Markdown, ```chem code blocks and inline code starting with "chem:", such as `chem:H2O`, are rendered. See examples/markdown.html for a working example.
